SEO rules

  • Each route sets title, description, canonical and Open Graph tags in its head().
  • Title pattern: “Product · Scentpocket”, home: “Scentpocket · A scent for every pocket”.
  • Product pages emit Product JSON-LD: name, brand, image, description, offers (price, priceCurrency NGN, availability InStock or OutOfStock). No fake ratings.
  • BreadcrumbList JSON-LD on product and tier pages; Organization + WebSite on home.
  • /sitemap.xml and /robots.txt as server routes. Disallow /checkout, /account, /admin, /auth.
  • noindex on account, checkout, sign in, admin and confirmation pages.
  • OG image per product: 1200×630 with name, price and dupe line.
  • Clean URLs: /p/, /shop?tier=pocket. One h1 per page.

PWA and mobile native rules

  • manifest.webmanifest: name Scentpocket, short_name Scentpocket, start_url /, display standalone, background_color #FAF6EF, theme_color #FAF6EF, icons 192, 512, 512 maskable.
  • Service worker: precache the app shell, offline fallback page, cache product images (stale while revalidate). Never cache server function responses, checkout or account.
  • Custom install sheet after the second visit or after a first order, never on first load. Dismiss remembers for 30 days.
  • Splash: the OS draws it from the manifest. In app logo splash only on standalone cold start, max 600ms.
  • viewport-fit=cover + env(safe-area-inset-*) on header, tab bar, sheets, toasts.
  • theme-color #FAF6EF to match the header.
  • No user-scalable=no. Inputs are 16px so iOS never zooms.
